# Limit Breaker — Mod Manager

Launcher para instalar, atualizar e gerenciar dublagens e conteúdos adicionais de **Dragon Ball: Sparking! ZERO** com poucos cliques.

> Windows 10/11 · 64-bit

## O que é

O Limit Breaker é um launcher que:

- mostra o catálogo de dublagens disponíveis para o jogo;
- instala e atualiza personagens, dublagens de mods e arquivos essenciais automaticamente;
- verifica novas versões do próprio launcher e avisa quando sair uma atualização.

## Como usar

1. Baixe e execute o instalador acima.
2. Abra o Limit Breaker e selecione a pasta `Content\Paks` do jogo.
3. Escolha o que deseja instalar e clique em **Instalar / atualizar**.

## Atualizações

O launcher verifica automaticamente se existe uma versão mais nova assim que é aberto. Quando houver, uma janela aparece oferecendo baixar e instalar a atualização na hora.
